 Job Portal
This project is a Job Portal application built using Mern Stack(MongoDB,Express.js,React.js and Node.js). It features user authentication, dynamic job listings, resume uploads, search/filter functionality, and role-based access for job seekers, recruiters, and admins.

🚀Features
🔒 User Authentication and Authorization

📝 Job Posting

👀 Application Management

🔍 Job Search

📑 Application Process

📱 Responsive Design

🛠️ User Profiles

📊 Dashboard (Manage users and requests)

🛠️Technologies Used
🗄️ MongoDB: For database management to store data.

🌐 Express.js: Backened framework for server-side logic.

⚛️ React.js: Frontened library for building the user interface.

🖥️ Node.js: For backend runtime environment.

🔗Usage
Sign Up: Create an account as an employer or job seeker.

Profile Setup: Complete your profile with relevant details to enhance your experience.

For Employers: -Post job listings with comprehensive details. -Manage and review applications from job seekers. -Use the dashboard to track and organize job postings and applications.

For Job Seekers: -Search for jobs using filters such as location, industry, and job type. -Apply for jobs that match your skills and interests. -Use the dashboard to track your applications and receive updates
